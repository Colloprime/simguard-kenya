SIMGUARD KENYA — PLATFORM OVERVIEW
====================================
Anti-Fraud SIM Registration & ID Protection System

VERSION: 1.0.4-beta
DATE: February 2026
REGION: Kenya

PROBLEM STATEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SIM card fraud is a growing crisis in Kenya. Common attack vectors include:

1. STOLEN SIM / PHONE
   - Criminal steals phone and uses it to access M-PESA and banking apps
   - Victim has no fast way to block the SIM remotely

2. SIM SWAP FRAUD
   - Criminal visits a Safaricom agent with a fake/stolen National ID
   - Requests a SIM swap for the victim's number
   - Gains access to all SMS-based 2FA (banking, M-PESA, email)

3. FRAUDULENT SIM REGISTRATION
   - Criminal uses a stolen National ID to register new lines
   - Lines used for scams, money laundering, or to impersonate the victim

4. AGENT-LEVEL FRAUD
   - Rogue Safaricom agents register bulk SIMs using fake or stolen IDs
   - Often part of organised crime networks

SIMGUARD SOLUTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SimGuard is a real-time fraud detection and citizen alert platform that:

  • Monitors every SIM registration attempt across Kenya
  • Cross-checks National IDs against the IPRS database in real time
  • Calculates a risk score (0–100) for every registration
  • Auto-blocks high-risk registrations before they complete
  • Sends instant SMS alerts to ID owners when their ID is used
  • Flags suspicious agents and geographic hotspots
  • Shares intelligence across all Kenyan telecom operators

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FRAUD DETECTION RULES ENGINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Risk Score Components:
  +40  ID on stolen/blacklist
  +30  Same ID used in 2+ counties within 6 hours
  +25  3+ registration attempts in 2 hours
  +20  Agent has >5 flagged registrations this week
  +15  Registration county differs from ID residence county
  +10  New agent account (< 30 days active)
  -10  ID previously verified with biometrics
  -15  Registration at official Safaricom Shop (not agent)

Thresholds:
  0–30   LOW     → Log only
  31–50  MEDIUM  → Alert owner via SMS
  51–70  HIGH    → Alert + require supervisor approval at agent
  71–85  HIGH    → Auto-suspend registration + alert owner + flag agent
  86–100 CRITICAL→ Auto-block + alert owner + notify CA Kenya + flag case

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ID WATCH — CITIZEN ALERT SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Citizens enroll their National ID number and an alert phone number.

When their ID is used for any SIM activity, they receive:

  SMS FORMAT:
  ─────────────────────────────────────
  [SimGuard Kenya] ALERT: Your National
  ID was used to register a new Safaricom
  SIM at Nairobi CBD (Agent AGT-0049)
  on 19/02/2026 at 14:32.

  Reply YES to approve or NO to BLOCK.
  ─────────────────────────────────────

Lock Modes:
  ALERT ONLY    → Notify owner, registration proceeds
  OTP LOCK      → Registration paused until owner approves via OTP
  FULL BLOCK    → All new registrations blocked; must visit shop to unlock

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
NEARBY AGENT LOCATOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The platform includes a real-time agent map showing:
  • All Safaricom agents within 5km of user location
  • Agent status: Verified / Under Watch / Flagged / Suspended
  • Distance from user in km
  • Operating hours and contact number
  • One-click "Report Incident Here" button

Agent Risk Classification:
  GREEN  → Verified, clean history
  AMBER  → Under watch (elevated but not confirmed fraud)
  RED    → Flagged / Suspended (do not use for sensitive requests)

STAKEHOLDER INTEGRATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  SAFARICOM KENYA
  → Primary integration: registration API, agent database, SMS gateway

  AIRTEL KENYA / TELKOM KENYA
  → Cross-operator ID flag sharing via CA Kenya feed

  COMMUNICATIONS AUTHORITY OF KENYA (CA)
  → Regulatory reporting, operator coordination, blacklist sharing

  NATIONAL REGISTRATION BUREAU (NRB) / IPRS
  → Real-time National ID verification and ownership lookup

  DIRECTORATE OF CRIMINAL INVESTIGATIONS (DCI)
  → Automatic referral for cases with risk score > 90

HOW TO REPORT A STOLEN SIM (CITIZEN GUIDE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 1 — SimGuard Platform (fastest)
  1. Open SimGuard Kenya dashboard
  2. Click "Report Incident"
  3. Enter your National ID and Safaricom number
  4. Select "Block SIM immediately"
  5. Submit — SIM is blocked within 60 seconds

OPTION 2 — Existing Safaricom channels
  • Call 100 (free, from any network)
  • Dial *106# to self-block
  • Visit any Safaricom Shop with your National ID

OPTION 3 — ID Fraud Alert (if ID is stolen, not SIM)
  • Enroll in ID Watch via SimGuard platform
  • You will receive alerts on every SIM registration using your ID
  • Reply NO to any alert to block the registration instantly
